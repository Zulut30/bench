# Подписочный эксперимент · 08.10.2026

Пользователь явно разрешил реальные генерации через свою подписку ChatGPT с
reasoning `xhigh`. API-ключи, платные API и ИИ-судьи не использовались.
Расходы разработки проекта и создания изображения не относятся к расходам бенчмарка.

## Условия

- Запрошенные модели: `gpt-6.1-sol`, `gpt-6-astra`, `gpt-6-sol`, `gpt-6-luna`.
  Доступность и поддержка xhigh проверены через официальный `model/list` клиента.
  Actual model ID в событиях ответов отсутствует; запрошенный ID не выдаётся за actual.
- Официальный Codex CLI **0.161.0**, ChatGPT login, forced_login_method=chatgpt,
  model_provider=openai. Закреплена копия установленного официального бинарника,
  SHA-256 `12ac11d2c7eee27cfae34393986d7b7c9ed0dea537cb749831cdd7033893e6de`.
  OAuth-файлы не читались. Это сравнение моделей в агентной оболочке Codex CLI,
  оно не переносится автоматически на веб-приложение ChatGPT.
- Один и тот же standard: 16 категорий, по одной задаче и одной попытке.
  Промпты, материалы и критерии сохранены. Отдельная версия набора
  `standard-1-xhigh-180s-32k`: 180 секунд генерации, 32 768 входных и выходных токенов;
  исполнение полученного кода ограничено отдельно. CLI output cap наблюдаемый.
- Последовательное исполнение через promptfoo; fresh ответы без локального кеша.
  Новая сессия/временная папка и OS sandbox; код исполняется в отдельном контейнере.
  Температура и внутренние retries неизвестны. Подмножества cache/reasoning не
  прибавляются к input/output второй раз.
- API бюджет и расход бенчмарка — $0. Стоимость фиксированной подписки и остаток
  квоты не определены. Один timeout имеет неизвестный usage, который не считается нулём.

В ней лежат конфиги, набор, каталог моделей, сведения о бинарнике и журналы,

## Исправления объективных проверок

Реальные ответы выявили ограничения, которых нет в промптах. Версия
`standard-checks-3` принимает альтернативные формы и сохраняет проверки дефектов:

1. Markdown-заголовок редакторской заметки; прежние версия, три пункта и числа.
2. Эквивалентные даты: `12 октября 2026`, `October 12, 2026`, `12 October 2026`.
3. Вложенные поля JSON архитектуры, SQL-алиас `event_id`, число попыток словами
   и русские формы «восстановление»/«восстанавливать». Слово outbox не является
   обязательным: смысл атомарности и идемпотентности проверяет будущий судья.
4. Цена в отдельных HTML-элементах без обязательного пробела; CTA допускает
   доступные кнопки и ссылки. Эстетика и качество взаимодействия остаются pending.
5. Не штрафуется нативная HTML-валидация за `user@example`: требование точки
   не задано в промпте, а [HTML Standard](https://html.spec.whatwg.org/multipage/input.html#email-state-(type=email))
   допускает single-label domain. Явно неправильные адреса продолжают проверяться.

Все доступные сохранённые ответы перепроверяются одной версией, без новых генераций.
Исходные `standard-checks-1` и первая перепроверка `standard-checks-2` сохраняются.
Объективный pass не является абсолютным баллом архитектуры, текста, перевода или
дизайна. Без судьи субъективная часть остаётся pending, в том числе при отказе
объективной проверки. Один ответ на категорию не даёт уверенного общего рейтинга.

сменился, старый путь исчез: семь ответов сохранены, девять локальных ошибок

он тоже не входит в таблицу четырёх текущих моделей. История не переписана.

Пример воспроизведения с сохранённым локальным конфигом (расходует подписочную квоту):

```bash
export DOCKER_CONTEXT=colima-bench
npm run bench -- run --provider codex-cli \
  --config results-chatgpt-xhigh-2026-10-08/gpt-6.1-sol-pinned.json \
  --results-dir results-chatgpt-xhigh-2026-10-08
```

При недоступности выбранной модели/входа/квоты запуск останавливается без платного
fallback. Приведённые model IDs и путь клиента проверены на дату эксперимента.
